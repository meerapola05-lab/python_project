The Smart Campus Information System was implemented as a web-based application using Flask, HTML, and CSS. The project integrates all the laboratory programs into a single interactive system for managing academic and student-related activities. The backend of the system was developed in Python using Flask. Different routes were created for handling functionalities such as student registration, course enrollment, fee calculation, file handling, directory scanning, student searching, sorting, and performance analytics. User input from the website forms is collected using request form and processed through Flask routes. Student details such as ID, name, age, marks, and grades are stored using Python dictionaries and lists.

Grade evaluation is performed using conditional statements. Course enrollment management validates the credit values and prevents invalid entries from being added. Student searching and sorting operations are implemented using loops and built-in sorting methods. Fee calculation is performed using user defined functions which compute tuition, hostel, and transport fees.

File handling is implemented using text files to store academic records permanently. The system also generates reports such as total number of students, average marks, and topper details. Directory scanning functionality is implemented using the Python os module. Exception handling techniques such as FileNotFoundError and a custom user defined exception (MissingFileOrFolder Error) are used to manage invalid paths and empty folders. Student performance analytics is implemented using: • NumPy for statistical calculations • Pandas for data handling • Matplotlib for graphical visualization

The frontend was designed using HTML and CSS with a responsive and themed interface. Flask templates were used to dynamically update tables, analytics, messages, and reports directly inside the webpage without opening separate pages. The project structure was modularized into: • app.py for backend logic • templates/index.htmlfor webpage structure • static/style.css for styling

This implementation demonstrates the integration of Python programming concepts, web development, file management, exception handling, and data analytics into a complete mini project system.
